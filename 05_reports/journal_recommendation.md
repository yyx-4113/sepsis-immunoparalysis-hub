# 投稿期刊推荐 — 方案三（v1.10.0, Methods & Resources / Computational Biology）

> 生成日期：2026-09-27（基于 v1.10.0 终稿）
> 证据层级判定：本稿为 **Methods & Resources / Computational Biology**——贡献是"可复现流程 + 诚实外部验证 + 实验蓝图"，**非新基因发现**。核心证据：Mars1 免疫麻痹程序为 near-replication（5 hub 复述已知 MARS 程序）；30 基因签名外部 AUC 0.638 vs IRG 基准 0.604（"comparable not superior"）；MR 层全 null（主结局 0/5 IVW 显著）。**无高新颖性生物学发现、无机制或前瞻功能验证。**
>
> 因此按证据层级闸门：**首推必须是对纯再分析/验证/阴性友好、重方法严谨的期刊（IF ≈ 2.6–7.5 档）**，高 IF 发现型顶刊（Genome Medicine / Nat Commun / Cell Reports Medicine / Briefings in Bioinformatics）仅作"补出前瞻/功能验证后"的冲刺档，**不作首投**。
>
> 所有指标均**联网核实**（2026-09-27），来源与年份见末列；JIF = Journal Impact Factor（Clarivate JCR / Web of Science），**≠ CiteScore（Scopus 指标）**，二者不可混用。

## 二、分层推荐

### A. 首推（证据层级匹配，按稳妥度排序）
1. **Scientific Reports** —— 最稳。重方法有效而非 impact，明确接受方法/验证类稿件； multidisciplinary 受众广；OA 可见度高。（注：你另一篇肠道菌群+PND 稿曾被 Sci Rep 拒，但那是不同稿件、不同证据问题；本稿为 Methods & Resources 框架，fit 不同，仍建议作为首选评估。）
2. **CSBJ** —— 方法/资源定位最正，IF 4.1 适中，Elsevier 平台、检索稳。
3. **JTM** —— 若想冲更高 IF（7.5）且强调"转化/实验蓝图"叙事，其重症监护/麻醉、医学生物信息板块对口；属你既定可接受清单（IF 6–8 档）。
4. **PLOS ONE** —— 最"诚实"的港：明确不因其"缺乏重要性"拒稿，适合本稿的 confirm/validate 定位，审稿稳健。

### B. 概念最契合但有红旗（先核实再投）
- **GigaScience** —— 其整刊定位（可重复大数据 + 管道即成果 + 数据/代码可用性）与本稿"fully auditable pipeline"几乎完美对应；但 2025 年编委集体辞职事件可能影响部分单位认定，**投稿前请确认贵单位/考核口径是否认可**。

### C. 契合但有边界/声誉 caveat（按情况选用）
- **BMC Bioinformatics** —— 仅当能突出"流程本身的某处方法学新颖性"时才稳；纯应用有 desk-reject 风险。
- **Frontiers in Immunology** —— 免疫学受众精准，但 Frontiers 家族近期声誉事件需查单位政策；且 CiteScore 远高于 JIF，填报时勿误写。
- **BMC Medical Genomics** —— IF 仅 2.0，但组学方法+感染免疫对口，是保守安全港。

### D. 冲刺档（**当前证据不支持首投**，仅补出前瞻/功能验证后考虑）
- Genome Medicine、Nature Communications、Cell Reports Medicine、Briefings in Bioinformatics —— 均要求明确、新颖、机制或转化过硬的实证；本稿 MR 全 null、签名为"comparable not superior"、无功能验证，当前投这些属 over-claim 风险。

## 三、文型映射（投稿时按目标刊选择）
- Scientific Reports → **Article**（方法/验证类按普通 Article 投）
- CSBJ → **Research Article / Methodology**
- JTM → **Methodology** 或 **Original Research**（突出 translational blueprint）
- PLOS ONE → **Research Article**
- GigaScience → **Application Note / Technical Note**（最契合 Methods & Resources）
- BMC Medical Genomics → **Research Article**（标注 bioinformatics methods）
- Frontiers in Immunology → **Computational Immunology** 板块 Original Research（或 Methods，若强调新方法）

## 四、关键纪律提醒
1. **CiteScore ≠ JIF**：Frontiers in Immunology CiteScore 10.8 是 Scopus 指标，JIF 仅 5.9；职称/考核填报以 SCIE-JIF（JCR）为准，勿混用，也勿把 "Q2" 不标清是 CiteScore 学科 Q 还是 JCR Q。
2. **数据可及性**：本稿已在 manuscript 写明 GitHub release tag v1.10.0 + Zenodo-on-acceptance；上述 OA 刊均要求代码/数据可用，与本稿一致，无额外负担。
3. **APC 预算**：Sci Rep ≈ $2,850；FIM ≈ $3,400；BMC 系列 €2,790–£2,290；CSBJ/JTM/PLOS ONE 为各自 OA 费率，投稿前以官网当期为准。
