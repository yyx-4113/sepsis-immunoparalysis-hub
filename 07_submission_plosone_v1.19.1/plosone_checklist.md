# PLOS ONE pre-submission checklist

## Soundness criteria (PLOS ONE judges these, NOT novelty/impact)
- [x] Original research (reproducible pipeline + novel 30-gene signature + in-silico drug repositioning blueprint).
- [x] Methods described in sufficient detail for reproduction (every number traces to a deposited file; 32 audit assertions).
- [x] Conclusions supported by the data (null MR explicitly framed as hypothesis-generating).
- [x] Written in standard English.
- [x] Ethics standards met (public de-identified data; analysis exempt from local IRB — see Ethics statement).

## Required statements present in manuscript
- [x] Ethics approval / exemption statement.
- [x] Data availability (GitHub + Zenodo DOI 10.5281/zenodo.23042366).
- [x] Code availability (MIT, CITATION.cff).
- [x] Author contributions.
- [x] Funding (none declared).
- [x] Competing interests.
- [x] Acknowledgements.
- [x] Generative-AI use disclosure (§2.12).

## Formatting
- [x] Unstructured abstract <=300 words (194, no citations).
- [x] References numbered in citation order, Vancouver style, DOIs present.
- [x] In-text citations bracketed [n].
- [x] Figures as separate PNG files; captions in manuscript.
- [x] Reporting guidelines: STROBE-MR checklist (S12) for the MR layer.
