All result tables (03_results/) and the analysis code are released under the MIT licence in the versioned repository at https://github.com/yyx-4113/sepsis-immunoparalysis-hub. A citable versioned snapshot is provided as a GitHub release (tag v1.19.1); a Zenodo DOI will be minted and made public on acceptance. A MANIFEST.csv with per-file checksums is included in the repository. The GSE65682 processed expression and phenotype matrix is regenerable from GEO (platform GPL13667) via the deposited processing scripts; E-MTAB-4451 is obtained as the published normalised matrix from ArrayExpress/BioStudies (platform GPL10558). The large raw inputs (approx. 43 GB) are mirrored per DATA_SOURCES.md and excluded from the repository for size. This study used and re-analysed public research data (GEO/ArrayExpress); no new primary data were generated. Supplementary tables S01-S12 accompany the manuscript as deposited CSV and figure files (see section 7 of the manuscript for the file map).
